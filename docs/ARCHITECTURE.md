## Состояние и хранение (браузер)
- `localStorage.igcal` — объект `S`: `ev, tasks, habits, goals, proj, tpl, inbox, cats, set, rep, aff, pts, timer, u …`
- По умолчанию `S.set = {theme:'light', ac:'#2f6bff', fs:15, r:12, tz:3, pw:''}`; категории: Работа, Учёба, Сон, Спорт, Агентство.
- Используемые ключи настроек: `ac, blk, dd, dig, dv, fx, gdoc, hide, m, menu, pw, sn, snd, tz, ws`.
- Другие ключи: `localStorage.igacc`, `igtok` (local/session), `igoff`; IndexedDB — автокопии.
- Часовой пояс: фиксированное смещение в часах `S.set.tz` (по умолчанию +3), и в клиенте (`tzNow`), и в Worker (`local(S)`). Переходов на летнее время нет.
- Идентификаторы: `uid()` = `Date.now().toString(36)+random`.

## Синхронизация
- Клиент: `sync()` каждые 10 секунд (`setInterval(sync,1e4)`), + при фокусе, `online`, `visibilitychange`. Пропускает цикл, если идёт перетаскивание/редактирование/открыт диалог.
- Алгоритм: GET `/state` → `mergeS` (слияние по `SYK=['ev','goals','proj','tpl','inbox']` с метками изменений) → при отличии PUT `/state` с `u`.
- Сервер: PUT принимается, если `b.u >= current.u` (last-write-wins по метке времени). Нет проверки размера и схемы.

## Worker (маршруты и ключи KV)
Маршруты: `/ping, /reg, /auth, /logout, /me, /pin, /setcred, /state, /tg, /tg/<PASSWORD>, /tgcode`.
Вход: PIN 5–8 цифр (хеш SHA‑256 с секретом) **или** логин+пароль (PBKDF2, `hp2`). Регистрация требует код `PASSWORD`. Лимит неудач: 15 на IP за 10 мин (`rl:<ip>`).
KV (привязка `CAL`): `accs`, `pin:<hash>`, `usr:<login>`, `<id>:login`, `tok:<token>` (TTL 1 год), `<id>:toks` (до 20), `<id>:state`, `<id>:chat`, `chat:<chatId>`, `tgc:<код>` (код привязки Telegram), `rl:<ip>`, служебные `await, snz, g<дата><i>…` (TTL 2 дня), устаревшие общие `state`, `chat`.
CORS: `access-control-allow-origin: *`. Вебхук Telegram: `/tg/<PASSWORD>` или `/tg` с заголовком `x-telegram-bot-api-secret-token == WEBHOOK_SECRET` (если задан).
Cron `* * * * *` → `scheduled` → для каждого аккаунта `runAcc`: сводки по расписанию, повторные напоминания (`snz`), аффирмации, напоминания за N минут.
Секреты: `BOT_TOKEN`, `PASSWORD`, (опц.) `WEBHOOK_SECRET`.

## Бот
Разбор текста (`parse`) — даты, время, длительности, повторы, «весь день», голос‑длинные сообщения → пункты → «Добавить все». Команды из `HELP` в worker.js (сейчас, дальше, свободно, итог дня, привычки, найди, правка по номерам, цели, таймер, дневник, в докс, главное, просрочено, идея, входящие, дублируй, пояс, сводка, вечер…). Привязка: 6‑значный код с сайта («Ещё → Аккаунт → Привязать Telegram») или PIN.

## Ограничения платформы (бесплатные планы — перепроверять актуальные цифры)
Cloudflare Workers Free: ограниченное число запросов в сутки и ограничения на KV (чтения/записи/удаления в сутки, запись в один ключ — не чаще раза в секунду). GitHub Pages: статический хостинг, сборки на стороне пользователя нет. Следствие: всё, что требует «npm build», выполняет ИИ в своей песочнице и отдаёт готовые файлы.
