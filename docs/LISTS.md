# IG calendar — итоговые списки для ИИ

Принцип продукта: **планирование должно быть приятным, удобным и гибким; каждая мелочь настраивается; по умолчанию — спокойно и просто.** Любая новая функция: (1) работает «из коробки» без настройки, (2) имеет понятную настройку в Центре настроек, (3) выключается целиком.

---
## 1. 30 значительных улучшений (S01–S30)
- **S01 Каркас проекта (A01–A04, A15, A20).** Разрезать index.html на файлы скриптом, добавить MAP.md и единый VERSION. Результат: любая следующая сессия читает 1–3 файла вместо 265 КБ; zip «только изменённые» становится по-настоящему маленьким.
- **S02 Единая система компонентов (A10, M01–M03).** Модальные окна, подтверждения, ввод, тосты, меню — одним кодом; убрать все `alert/prompt/confirm`. Это основа «приятного» интерфейса.
- **S03 Дизайн-токены и конструктор темы (M01, M08).** Любой цвет акцента, радиусы, плотность, шрифт, размер; тёмная/«Сон»/«Учёба»/«Авто по времени суток».
- **S04 Центр настроек с поиском и сбросом (M06, A18).** Каждая деталь — переключатель/ползунок/список; у каждой настройки описание и «по умолчанию».
- **S05 Профили интерфейса (M07).** «Минимализм / Фокус / Планирование / Агентство» + свои; смена за один клик, чтобы мозг «расслаблялся при входе».
- **S06 Надёжная синхронизация (B01–B05, B08).** Версия вместо полного опроса, серверное время, слияние по полям, очередь офлайн-изменений, экономный режим — под бесплатные лимиты Cloudflare.
- **S07 Корзина и история версий (B06, B07, B09).** Любую ошибку можно отменить: восстановление удалённого и откат состояния.
- **S08 Часовые пояса по стандарту (E09, из «Фактов» №7).** IANA-зоны (например `Europe/Berlin`) вместо фиксированного смещения — сайт и бот одинаково переживают летнее время; вторая шкала времени.
- **S09 Тесты в песочнице ИИ (A13, A14).** Общее ядро дат/повторов/парсинга для сайта и бота + автотесты; ИИ запускает их перед выдачей zip.
- **S10 Безопасность без неудобства (C01–C06).** Секрет вебхука отдельно, строгий CORS, список устройств, хеш токенов, блокировка при переборе; вход остаётся быстрым.
- **S11 Календарь 2.0: умная раскладка и привязки (E01–E03, E12).** Пересечения, магнитные границы, подсказка времени, масштаб колесом.
- **S12 Виды «Повестка», «N дней», «Рабочая неделя» (E07, E08).** Гибкий выбор того, как смотреть на время.
- **S13 Слои-календари с индивидуальными настройками (E11, E15).** Работа/Личное/Агентство: цвет, рабочие часы, длительность по умолчанию, напоминания.
- **S14 Панель этапа в два уровня (F01, F03, F04).** Основное сверху, остальное в сворачиваемых секциях; подзадачи с прогрессом.
- **S15 Быстрый ввод 2.0 (F02, F03).** Живая подсветка распознанных частей, `#проект @тема !! ~30м`, автодополнение.
- **S16 Повторы уровня Google Calendar (F07).** «Каждый 2‑й вторник», «последний рабочий день», исключения, «только этот / этот и следующие / все».
- **S17 Задачи как полноценная система (G01–G07).** Входящие, статусы, даты начала/срока, зависимости, пакетные операции, виды список/доска/таймлайн.
- **S18 Привычки 2.0 (G08–G10).** Гибкие расписания, количественные цели, тепловая карта, стеки, щит серии с настройкой.
- **S19 Иерархия целей и OKR (G11–G13).** Цель → подцели → проекты → задачи; веса, прогноз, недельные чекины.
- **S20 Проекты-папки с мини-календарями (G14–G16).** Подпапки, свои настройки, «Агентство» разворачивается в проекты внутри.
- **S21 Финансы проекта (G17).** Ставка, часы, выручка, план/факт — включается галочкой, по умолчанию скрыто.
- **S22 Фокус-режим и помодоро-профили (H01–H05).** Полноэкранный минимализм, привязка к задаче, автопауза, звуки (Web Audio, бесплатно).
- **S23 Отчёты 2.0 (I01–I05, I08).** Сравнение периодов, инсайты, тепловая карта, печатные шаблоны, экспорт CSV/PDF.
- **S24 Недельный обзор-мастер (I06).** 5 шагов раз в неделю: итоги → хвосты → входящие → цели → план.
- **S25 Бот 2.0: пульт и модули (J01–J03, J06, J09).** Разделённый код, главное меню кнопками, закреплённое «состояние дня», сводки с действиями.
- **S26 Бот: надёжность и вежливость (J04, J05, J07, J12, J13).** Предпросмотр неоднозначного, защита от дублей, «не беспокоить», разбиение длинных ответов.
- **S27 Центр уведомлений (K01, K02, F08).** Единые правила: что/когда/куда, группировка, умная отсрочка, тихие часы, несколько напоминаний на этап.
- **S28 Мобильная версия «как приложение» (L01–L06).** Проверенное удаление/настройка этапа, жесты, настраиваемая нижняя панель, шторки, клавиатура, обновление PWA.
- **S29 Доступность и язык (M10, M12, M13).** WCAG AA, клавиатура, aria, RU/EN, форматы.
- **S30 Резервные копии и перенос (B13, B15, C09).** Один файл «всё», автокопии с настройкой, экран блокировки, вход по ссылке-приглашению (одноразовой).

## 2. 40 новых функций (N01–N40)
- **N01 Планировщик дня «Автораскладка».** Перечень задач с оценкой времени → кнопка «Разложить по свободным окнам» с учётом приоритета и энергии; можно подтвердить/подвигать.
- **N02 «Что делать сейчас?»-кнопка.** Предлагает одну задачу по приоритету, оставшемуся окну и контексту (в схеме уже есть зачаток — довести).
- **N03 Режим «Опаздываю / перестроить день».** Сдвигает оставшиеся этапы дня на N минут и предлагает убрать наименее важное.
- **N04 Типовой день и типовая неделя.** Сохранить, применять к любому дню; «план по шаблону на следующую неделю».
- **N05 Блоки «глубокой работы».** Закрепляемые окна в календаре, защищённые от случайных встреч; бот и сайт предупреждают.
- **N06 Буферы.** Автоматические 5/10/15 минут между встречами (настройка по теме).
- **N07 Время в пути.** Поле «дорога» у этапа с местом; блок-призрак перед встречей.
- **N08 Ссылка для записи на встречу (booking).** Публичная страница со свободными окнами; клиент выбирает слот → этап создаётся (через Worker, бесплатно).
- **N09 Импорт из Google Calendar по ссылке-ICS (подписка).** Автообновление раз в N часов, только чтение (в схеме есть импорт .ics — сделать подпиской).
- **N10 Экспорт-подписка (ICS-URL) для чтения календаря в других приложениях.**
- **N11 Календарь недели «Главные 3».** Три приоритета недели закреплены вверху; бот напоминает.
- **N12 Ежедневный «фокус-вопрос» утром.** «Что сделает день успешным?» → становится главной задачей и показывается в «Сейчас».
- **N13 Вечерний итог-ритуал.** Что получилось / что перенести / благодарность; запись в дневник, серия дней.
- **N14 Дневник с настроением и тегами.** Поиск по дневнику, «год назад в этот день».
- **N15 Заметки-страницы.** Простые заметки (с чек-листами и ссылками), привязываются к проекту/цели/этапу, поиск по ним.
- **N16 Идеи и «когда-нибудь».** Отдельный список с «созреванием»: бот раз в неделю предлагает вернуться.
- **N17 Список чтения/просмотра/покупок.** Мини-списки с отметками (универсальные «коллекции» с настраиваемыми полями).
- **N18 Трекер финансов целей.** Цель в ₽ (доход агентства): записи «+5000», график, прогноз; бот-кнопка «+». (Расширяет текущие цели.)
- **N19 Контакты/клиенты.** Карточка клиента: проекты, часы, последние этапы, заметки, дата следующего контакта.
- **N20 Напоминание «связаться с клиентом».** Если с клиентом не было этапов N дней — бот напоминает.
- **N21 Шаблоны отчёта клиенту.** Выбор клиента → период → готовый текст/PDF по услугам и часам.
- **N22 Счётчик «времени на услугу».** SEO / Сайты / Реклама / Контент: недельная норма, остаток, предупреждение о перерасходе.
- **N23 Спринты недели/месяца.** Цель периода, список задач, итог в конце; шкала выполнения.
- **N24 Канбан-доска для проекта** с колонками-статусами и счётчиком часов в колонке.
- **N25 Таймлайн/Гант проекта.** Горизонтальная лента задач и целей по датам, перетаскивание.
- **N26 Матрица Эйзенхауэра.** Отдельный вид для разбора задач.
- **N27 Энергия и сон.** Отметки в течение дня, график «когда я продуктивен», подсказки по планированию тяжёлого на пик.
- **N28 Привычки-«челленджи».** 21/30/66 дней со шкалой и поддерживающими сообщениями.
- **N29 Достижения и уровни (мягко).** Значки за серии/часы/цели; очки и уровень остаются, но можно скрыть всё одной кнопкой.
- **N30 Музыка/звук фокуса.** Встроенные шумы (дождь, кафе, белый), громкость, автостарт с таймером.
- **N31 Недельный обзор по расписанию в боте** (воскресенье вечером) — запускает мастер на сайте и краткую версию в Telegram.
- **N32 Командная палитра 2.0 (`Ctrl+K`).** Поиск по всему + действия («создать задачу», «перейти к проекту», «включить тему Сон»).
- **N33 Глобальный поиск с фильтрами.** По названиям, заметкам, дневнику, тегам; сохранённые поиски («Просроченное по SEO»).
- **N34 Умные списки (saved filters).** «Важное на этой неделе», «Ждёт ответа», «Без проекта» — закрепляются слева.
- **N35 Быстрый захват виджетом/ярлыком.** Кнопка «Записать» на главном экране телефона (ярлык PWA + `share_target`).
- **N36 Совместный доступ «только чтение» на ссылку.** Для помощника/клиента: этапы по тегу «клиент Х» (с паролем и сроком жизни).
- **N37 Помощник-ассистент, «разбор на подзадачи» без платного ИИ.** Правила и шаблоны: «Запуск рекламы» → 8 подзадач; редактируется пользователем.
- **N38 Режим «Путешествие / отпуск».** Скрывает рабочие этапы, ставит бота на паузу, возвращает «хвосты» при возвращении.
- **N39 Мастер первого запуска и «чек-лист здоровья сервиса».** Проверка бота, Google Docs, синхронизации, копий — зелёные галочки.
- **N40 История изменений для пользователя («что нового»).** Окно после обновления: 3–5 пунктов простым языком + ссылка «как включить».

## 3. 20 старых функций — как улучшить (O01–O20)
- **O01 Сетка дня/недели.** Сейчас пересекающиеся этапы делят ширину нестабильно → алгоритм колонок (E01); короткие этапы — раскрытие по клику, а не только наведению (на телефоне наведения нет).
- **O02 Быстрый ввод.** Показывает дату/время под строкой → добавить подсветку распознанных частей, исправление щелчком по ним, историю последних фраз.
- **O03 Панель этапа.** Вместо длинного списка полей → секции с запоминанием раскрытия, поиск по проектам в выпадающих списках, создание проекта в маленьком окне.
- **O04 Выбор времени.** Сетка + стрелки есть → добавить ввод цифрами (`1430`), быстрые кнопки «Сейчас / +30 мин / вечером», учёт часового пояса.
- **O05 Чек-лист.** Превратить в подзадачи: даты, исполнитель/заметка, процент выполнения этапа от пунктов.
- **O06 Повторы.** Кроме `daily/weekly/monthly/yearly` — правила (каждый N-й, последний рабочий), исключённые даты, «только этот».
- **O07 Выделение и групповые действия.** Панель снизу → добавить «проект», «услуга», «дата», «перенести на день», сохранение выделения при переключении вида.
- **O08 Таймер.** Привязка к задаче, ручная правка записи, автопауза, защита от «забыл остановить», показ в заголовке вкладки.
- **O09 Цели.** Из «числа и срока» → иерархия, вес подцелей, прогноз и светофор; в боте «+5000» с выбором цели кнопками.
- **O10 Привычки.** Щит серии есть → расписания «3 раза в неделю», количественные, тепловая карта года, напоминание в «слабое» время.
- **O11 Проекты.** Окно настройки вместо `prompt()`, цвет/клиент/ставка/план часов/архив, папки и мини-календари.
- **O12 Отчёты.** Показатели есть → сравнение периодов, цели «план/факт», экспорт CSV/PDF, шаблон отчёта клиенту.
- **O13 Отчёт в Google Docs.** Сейчас по заголовку-дате заменяет раздел → добавить выбор шаблона разделов (что включать), отправку недели/месяца, ссылку на документ в интерфейсе и проверку «скрипт отвечает» кнопкой.
- **O14 Аффирмации.** Категории, вес показа, привязка к событиям, отдельная «тихая» плашка без кнопки (с авто-скрытием настраиваемым временем).
- **O15 Бот: парсер.** «через 30 минут», «с 14 до 16», «весь день» есть → «в пятницу утром/вечером», «через неделю», «в конце месяца», диапазоны дат, названия людей, русские числительные («в три часа»).
- **O16 Бот: правка по номеру.** Номера привязаны к показанному списку → хранить «последний показанный список» на час и явно писать «действует для списка от 14:05».
- **O17 Вход и аккаунты.** PIN + пароль → экран входа с понятными ошибками, «показать пароль», быстрый вход по биометрии (WebAuthn, где доступно), список устройств.
- **O18 Синхронизация и индикатор.** Точка у шестерёнки → подробный статус по клику («последняя синхронизация 12:31, ждёт отправки: 2, ошибка: нет связи»), кнопка «Синхронизировать сейчас».
- **O19 Экспорт/импорт.** JSON/.ics → предпросмотр импорта, «объединить / заменить / только новые», экспорт отдельных проектов и периодов.
- **O20 Service worker.** Кеш есть → показать «Доступна новая версия», режим «обновлять при следующем запуске», очистка старых кешей и версия кеша из VERSION.

## 4. UX/UI: что добавить и изменить (U01–U20)
- **U01 Кнопка «+» плавающая везде (на телефоне — по центру)** с выбором: событие, задача, привычка, заметка, таймер.
- **U02 Верхняя строка «Сейчас»:** текущий этап, остаток времени, следующий, кнопка «Готово» — всегда видна; клик открывает этап.
- **U03 Кнопка «Фокус на день»:** прячет всё, кроме сегодняшних этапов и главной задачи.
- **U04 Переключатель профилей интерфейса в шапке** (иконка палитры): 4 готовых + свои.
- **U05 Панель быстрых фильтров над календарём:** слои (чипы) с цветом и галочкой; кнопка «Показать только мои приоритетные».
- **U06 Контекстное меню по правому клику/долгому нажатию:** выполнено, дублировать, перенести (завтра/в понедельник/выбрать), цвет, проект, удалить.
- **U07 Отмена/Повтор (Undo/Redo)** кнопками в шапке и горячими клавишами, история последних 20 действий.
- **U08 Выезжающий список дня в месяце** при клике по дню + «+» для быстрого добавления.
- **U09 «Сегодня» с большим приветствием по времени суток** и 3 главными: главная задача, ближайшее, привычки; цитата/аффирмация — настройка.
- **U10 Дыхание/пауза 60 секунд:** кнопка в боковой панели — таймер с анимацией «вдох-выдох» для расслабления между задачами.
- **U11 Прогресс дня:** тонкая шкала (задачи + привычки + часы плана) в шапке, мягкая подсветка на 100%.
- **U12 Мини-обучение подсказками:** первое появление каждой функции — одноразовая подсказка (можно отключить всё).
- **U13 Всплывающая справка «?» у каждой настройки** и ссылка «Что это?» с короткой картинкой/гифкой.
- **U14 Тёмная тема без «чёрной дыры»:** графитовые уровни поверхностей (3 уровня), акцент приглушён; проверка контраста.
- **U15 Автотема по расписанию:** день — светлая, вечер — «Сон», режим учёбы — «Учёба» по команде/расписанию.
- **U16 Крупный режим «для телефона одной рукой»:** кнопки действий внизу, свайп-панели, увеличенные зоны нажатия.
- **U17 Скелетоны и плавная загрузка** вместо «пустых» мигающих блоков; индикатор синхронизации не прыгает.
- **U18 Единые отступы и сетка 4/8 px**, максимальная ширина читаемых блоков, выравнивание иконок и текста; иконки одной толщины.
- **U19 Звуки и вибрация (по настройке):** тихий «щелчок» выполнения, мягкий сигнал напоминания, вибрация на телефоне; громкость и набор звуков.
- **U20 Страница «Что нового» и «Как это работает»:** в приложении, с кнопками «Включить»/«Попробовать» рядом с каждой новой функцией.
