# SMOKE — проверка за 5 минут после каждого обновления
Отмечайте галочками, ошибки пишите коротко: «где нажал → что ожидал → что получилось».
1. [ ] Сайт открывается, в консоли нет красных ошибок (F12 → Console; на телефоне — меню диагностики).
2. [ ] Вход выполнен, точка синхронизации зелёная.
3. [ ] Создать этап кликом по сетке, переименовать, перетащить, растянуть, удалить, «Отменить».
4. [ ] Создать задачу и привычку, отметить выполненными.
5. [ ] Быстрый ввод: «завтра в 15:00 созвон на 1ч» создаёт этап на завтра.
6. [ ] Таймер: старт → стоп → этап появился.
7. [ ] Отчёты открываются, цифры не «NaN».
8. [ ] Телефон: открыть, создать этап, открыть панель, удалить этап, изменить время.
9. [ ] Бот: «сейчас», «завтра», создать этап текстом, «отмена».
10. [ ] Выключить интернет → страница открывается, изменения сохраняются; включить → точка зелёная.
11. [ ] Версия в интерфейсе совпадает с версией из сообщения ИИ (если нет — GitHub Pages ещё не обновился, подождите 1–2 минуты и нажмите Ctrl+F5).
